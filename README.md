# ZeroToShip

Repository setup for **ZeroToShip | Summer Activity 2026**.

## Suggested Structure

```text
ZeroToShip/
├── Phase-1/
├── Phase-2/
├── Phase-3/
├── Phase-4/
├── Phase-5/
└── Final-Integration/
```

## Guidelines

- Keep a clean, incremental commit history (avoid one-time bulk uploads).
- In each phase folder:
  - maintain a `README.md` for progress, approach, and learnings,
  - keep an `Output/` folder for screenshots or demonstrations.
- Use `Final-Integration/` for the final integrated project and complete documentation.
